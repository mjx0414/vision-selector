# 机器视觉选型计算器

输入**最大视野（mm）**与**精度要求（mm）**，自动推算需要什么规格的工业相机与镜头。

## 使用方式

方式一：直接打开线上版本 👉 https://mjx0414.github.io/vision-selector/

方式二：下载 `vision-selector.html`，双击用浏览器打开即可，**完全离线可用**，无需安装任何东西。

## 功能

- 输入视野长/短边 + 精度要求（检测精度 mm 或像素精度 mm/px）
- 自动推算所需分辨率，并从 15 档标准面阵机型（0.3MP~26MP、1/4"~4/3" 靶面）中选出最小满足方案
- 推荐镜头焦距、靶面、接口、解像力（lp/mm）
- 可行性校验：暗角、镜头解像力不足、倍率过大需远心、WD 处视野覆盖不足等常见错误逐条提示
- 备选机型对比表、焦距 ↔ 工作距离对照表
- 一键复制选型报告

## 计算规则

| 项目 | 公式 |
|---|---|
| 所需像素精度 | 检测精度 ÷ 亚像素系数（默认 3） |
| 所需像素数 | 视野 ÷ 像素精度（长边、短边分别校验） |
| 光学放大倍率 | β = 传感器宽 ÷ 视野宽 |
| 焦距 | f = WD·β/(1+β) |
| 工作距离 | WD = f·(1+1/β) |
| 镜头解像力要求 | 1000 ÷ (2 × 像元 μm) lp/mm |
| 景深 | DOF = 2·F·c·(1+β)/β²，c 取 2 个像元 |

> 注：工作距离为薄透镜理论值，实际镜头主面偏移会使真实 WD 短 10~25 mm，落地前请以镜头规格书的 WD–FOV 曲线复核。
